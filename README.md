# 腎超修改版

腎臟超音波 AI 研究系統的重建版本：把訓練網站（ISU_AI_KUA）與「腎超新」整合成一套，所有模型重新訓練。

- **接手請從 [01_計畫與文件/README.md](01_計畫與文件/README.md) 開始**：閱讀順序、文件地圖、專案現況、規則、名詞表。
- 計畫：[整合計畫](01_計畫與文件/整合計畫.md)、[實作企劃](01_計畫與文件/實作企劃.md)、[決策紀錄](01_計畫與文件/決策紀錄.md)、[標註規範](01_計畫與文件/標註規範（草稿）.md)
- 目前進度：**M1 資料基礎、M2 訓練與模型已完成**（[M1](01_計畫與文件/里程碑報告/M1.md)、[M2](01_計畫與文件/里程碑報告/M2.md)）；**M2.5 程式已完成**（[M2.5 報告](01_計畫與文件/里程碑報告/M2.5.md)，含你接下來要做的事）：醫師圈選、eGFR 2／3／5 類比較（影像、臨床、遮罩）、eGFR／分割／回音分級三區分開、移除影像品質、資料夾整理。**M3（醫師端）程式已完成**（[M3 報告](01_計畫與文件/里程碑報告/M3.md)、[雙機展示步驟](01_計畫與文件/雙機展示步驟.md)）：兩台筆電網頁傳圖、自動去識別化與分析、檢查工作區、報告簽核與 PDF；直接接超音波機器要等 IRB。
- 真實資料現況：975 張影像、181 位病人、split-0002（測試集 36 位）、eGFR ①②③ × 2／3／5 類共 9 個訓練（交叉驗證 AUC(<60) 最高 0.786）；遮罩與回音分級目前 0 筆。

## 使用方式

| 檔案 | 用途 |
|---|---|
| `setup.bat` | 第一次使用（或換電腦）時執行：建立 Python 虛擬環境、安裝套件（含 CUDA 版 PyTorch，約 3 GB）、建置前端。需要 Python 3.12、Node.js 20 以上與 pnpm |
| `start.bat` | 啟動系統，瀏覽器會自動開啟。關閉這個視窗就會停止系統 |
| `stop.bat` | 停止系統 |
| `backup.bat` | 完整備份（含影像與模型）到外接硬碟。先執行 `stop.bat` |

- 不需要登入。第一次使用時，先到「設定 › 醫師與操作者名單」建立名單，再從右上角選擇操作者。醫師名單用於回音分級的判讀者、模型升為臨床上線的核准醫師，以及之後醫師端的報告簽核（醫師圈選不需要選醫師）。
- 只接受本機連線，其他電腦無法開啟。
- 每天第一次啟動時，會自動快照三個資料庫到 `07_備份\每日資料庫`，保留 14 天。

| 資料夾 | 內容 |
|---|---|
| `IMG_original/` | 原始照片，唯讀，登記為匯入批次 B0000。影像上燒有病人個資，不可上傳或外流（唯一例外：醫師圈選時勾選匯出原始影像，需確認文字、寫稽核、只存受限區；IRB 已確認允許，D50） |
| `01_計畫與文件/` | 計畫、規格、標註規範、決策紀錄、里程碑報告；`Deep_research/` 放研究報告與筆記 |
| `02_程式碼/` | `backend` 後端、`frontend` 介面、`scripts` 啟動與備份腳本 |
| `03_資料/` | 系統管理的研究資料：`00_資料庫`、`01_原始封存`（含個資，受限；也存上傳過的病人表）、`02_去識別化影像`、`03_人工標註`、`04_模型產出`（預測遮罩、特徵、流程結果；M2.5 新增預測遮罩組）、`05_資料集版本`、`06_資料切分`、`07_匯入紀錄`、`08_匯出`、`09_索引`（M2.5：不含個資的 CSV，可直接用 Excel 查找影像、遮罩、訓練）。**不要手動修改** |
| `04_模型/` | 訓練紀錄、模型庫、評估、預訓練權重、nnUNet。M2.5 起訓練、模型庫、評估依任務（eGFR／分割／回音分級）分資料夾，訓練資料夾附 `摘要.txt` |
| `05_醫師端/` | 醫師端：`01_原始`（受限）、`02_影像`、`03_報告`（每份報告一個 PDF）、`04_分析`、`05_接收暫存`（受限） |
| `醫師圈選網站/` | 獨立的本機圈選網站。`資料/` 有含個資的原始影像，只能留在本機 |
| `06_匯入區/` | 新收案：把影像與病人表放進 `待匯入\{資料夾}`；匯入後移到 `已完成` |
| `07_備份/` | 每日資料庫快照與完整備份紀錄 |
| `08_系統/` | 日誌、暫存、執行狀態；可以刪除，系統會重建 |

各資料夾的詳細設計見[資料庫與檔案設計](01_計畫與文件/資料庫與檔案設計.md)第 2 節。M2.5 起每個資料夾另有 `說明.txt`，網頁上也有「在檔案總管開啟」按鈕。

## 醫師圈選網站

醫師在獨立的本機網站圈選全部影像，不併入主系統（[說明](醫師圈選網站/README.md)、[報告](01_計畫與文件/里程碑報告/醫師圈選網站.md)）：

1. 「標註與回饋 › 醫師圈選」按「選取全部影像（圈選網站）」，匯出時勾選原始影像。
2. 把 `醫師圈選網站/發布版/醫師圈選` 放到要圈選的電腦，雙擊 `啟動.exe`，「匯入影像」填匯出的資料夾。
3. 醫師圈選、判回音；隨時可以按「輸出結果」。
4. 回到主系統「上傳醫師圈選」填輸出資料夾路徑，檢查後匯入。

## 醫師圈選（M2.5，不用網站時）

醫師不在本系統中畫圖，流程是：

1. 「標註與回饋 › 醫師圈選」建立批次（先做測試集：每位測試病人每側 1 張；之後每批約 100 張）。
2. 按「匯出給醫師」，把產生的 zip（去識別化影像、`清單.csv`、`圈選說明.txt`）交給醫師。需要時可勾選另外匯出原始影像。
3. 醫師在圖上用顏色圈出腎臟外框、腎竇、肝、脾，**檔名與尺寸不要改**，傳回給你。
4. 第一次匯入前，到「設定 › 顏色對照」指定每種顏色代表的構造。
5. 「上傳醫師圈選」填傳回的資料夾路徑，檢查疊圖後匯入。
6. 用累積的遮罩訓練分割模型（「分割 › 分割訓練」），看學習曲線決定要不要下一批。
7. 分割夠好後，到「分割 › 遮罩組」產生遮罩組：每位病人用沒看過他的那一折模型預測遮罩，並自動擷取量測特徵。

## eGFR 比較（M2.5）

1. 「eGFR 預測 › eGFR 訓練」勾選輸入方式與類別數（2／3／5 類），勾了哪些就訓練哪些：
   - 無遮罩：① 影像、② 影像＋臨床資料（糖尿病、年齡、性別）、③ 純臨床資料。
   - 有遮罩（需要遮罩組）：④ 影像＋遮罩通道、⑤ 影像＋遮罩量測、⑥ 純遮罩量測。
2. 比較頁看每一格的病人層級 AUC(<60)，跑預先指定的主要比較（② vs ③）與任兩格的配對 bootstrap，可匯出 CSV 到 `03_資料\08_匯出`。
3. 全部比較組都訓練完後，在比較頁勾選要一起評估的比較組，評估固定測試集（只能一次，只鎖 eGFR）。

## 開發

```bash
cd 02_程式碼/backend
.venv/Scripts/python.exe -m pytest
```

```bash
cd 02_程式碼/frontend
pnpm dev
```

前端開發伺服器在 http://localhost:5173，API 會轉到 `127.0.0.1:8000`（先用 `start.bat` 或 `scripts/run_server.py` 啟動後端）。測試只使用程式產生的假影像，不會讀寫 `IMG_original` 或 `03_資料`。
