# 醫師圈選網站

獨立的本機網站：專責醫師在原始超音波影像上圈選器官、病灶並判回音，結果上傳回主系統。程式不依賴主系統。決策見 D46–D51。

## 使用

1. 把 `發布版/醫師圈選` 整個資料夾放到要用的電腦（不用安裝）。
2. 雙擊 `啟動.exe`，瀏覽器會開啟網站；不要關閉黑色視窗。
3. 首頁「匯入影像」填主系統匯出的原始影像資料夾路徑，填「圈選者代號」。
4. 「繼續圈選」開始；圈完前 20 張後，首頁會顯示預估剩餘時間。
5. 首頁「輸出結果」隨時可以按，結果在 `輸出/`；把路徑填到主系統「上傳醫師圈選」。

## 快捷鍵

| 鍵 | 功能 |
|---|---|
| `1`–`9` | 切換項目 |
| `T` `P` `A` `E` | 描邊、點選、調整、擦除 |
| 滾輪、空白鍵拖曳、`0` | 縮放、移動、回到全圖 |
| `Ctrl+Z`、`Ctrl+Y` | 復原、重做 |
| `H` | 隱藏或顯示圈選 |
| `Enter` | 封閉多邊形；否則完成並到下一張 |
| `←` `→` | 上一張、下一張 |

## 資料夾

| 路徑 | 內容 |
|---|---|
| `資料/影像/` | 匯入的原始影像，**含個資，不可上傳或外流** |
| `資料/圈選.sqlite3` | 圈選資料庫，每次操作自動儲存 |
| `資料/備份/` | 啟動時與每 30 分鐘的資料庫備份，保留 30 份 |
| `輸出/` | 給主系統的結果，不含影像內容 |

輸出資料夾：`標籤/{影像ID}.png`（單通道、原尺寸、0–4）、`圈選結果.json`、`圈選結果.csv`。不要在輸出資料夾放其他影像檔，主系統會掃描所有影像，同一個影像 ID 只留較新的檔案。

## 開發

```bash
cd backend
.venv/Scripts/python.exe -m pytest
```

```bash
cd frontend
pnpm dev
```

- 第一次：`py -3.12 -m venv backend/.venv`，安裝 `backend/requirements-dev.txt`；`frontend` 執行 `pnpm install`。
- `backend/demo.py` 用暫存資料夾與合成影像啟動網站（連接埠 8130），不碰真實資料。
- 打包發布版：`backend/.venv/Scripts/python.exe build.py`。
- 測試只用合成影像。
