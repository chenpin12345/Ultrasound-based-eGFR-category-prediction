## 1. 結論

M2 的功能都完成了，而且在顯示卡上實際跑過整個流程：

- **標註準備**：舊程式遮罩匯入、規則產生肝／脾草稿、草稿逐張確認。
- **訓練**：在獨立程序執行，可停止、恢復、比較。
- **模型**：註冊模型、固定測試集只能評估一次、回音特徵、一鍵流程與 AI 分析。

驗證結果：

- 後端自動測試 **56 項全部通過**，前端型別檢查與建置都通過。
- 「停止後恢復」實測和不中斷時**完全相同**：模型權重逐位元相同，訓練紀錄相同。

有一項依真實資料修改了原本的計畫。MedSAM 在真實影像上**只圈到腎臟的一半左右，而且漏掉皮質**，所以：

- 腎臟草稿改以**舊遮罩為主**；
- MedSAM 改成選用的比較工具。

證據見第 4 節 #44。

**本階段沒有替你訓練任何正式模型**，測試時用的都是幾個 epoch 的極小模型，結果沒有意義。

### 2.2 M2-1 訓練與模型

| 功能 | 內容 |
|---|---|
| 訓練任務 | 分割（背景、腎實質、腎竇、肝、脾）、eGFR < 60、回音分級 Grade 0–3、影像品質 |
| 架構 | 分割：UNet＋ResNet-34 編碼器或經典 UNet。分類：ResNet-18／34，可接腎長、回音比值等特徵（late fusion） |
| 輸出頭 | binary、CE、**正確版 CORAL**（所有門檻共用權重）、CORN、SORD |
| 部分標註 | 只有整顆腎或沒有肝脾的遮罩，用「類別群組」計算 loss，缺的類別不會被當成背景教錯 |
| 訓練引擎 | 固定的病人層級切分；最佳 epoch；完整 checkpoint（含所有亂數狀態）；AMP；梯度累積；提早停止；out-of-fold 預測；校準溫度與 ECE |
| 獨立程序 | 訓練在另一個 Python 程序執行，網站不載入 PyTorch；一次只跑一個；網站重啟時訓練程序會自己停下，不會留下孤兒程序 |
| 預訓練權重（D2） | 訓練頁一鍵下載（MedSAM 已下載；ResNet-18／34 ImageNet 用到時再下載），附 sha256 |
| nnU-Net v2 基準 | 自動轉成 nnU-Net 格式，用同一個切分，可選 100／250／1000 epochs，結果可以和內建 UNet 逐折比較 |
| 回音特徵 | 皮質＝腎實質外層帶；參考組織只取同深度的肝或脾；排除 caliper 與過曝像素；平均值與中位數；右腎／肝、左腎／脾分開做 Spearman 相關；自動腎長對技師 Dist A 的 Bland-Altman |
| 交叉擬合 | 下游模型只能用「分割訓練的 out-of-fold 遮罩」算出的特徵；用人工遮罩算的特徵會被拒絕 |
| 實驗 | 範本：隨機初始化 vs ImageNet；消融 A0–A5（含打亂特徵的負對照）。建立後是草稿，由你按開始；逐折差異用 Nadeau-Bengio 校正 t 檢定 |
| 模型庫 | 合約 v2 manifest、模型卡、sha256；推論前檢查合約，不符或檔案被改過就拒絕 |
| 階段 | 研究 → 候選 → 臨床上線 → 退役；臨床上線要輸入模型名稱，並從醫師名單選核准醫師 |
| 評估 | out-of-fold：影像與病人層級、以病人為單位的 bootstrap 95% 信賴區間 |
| 固定測試集 | 只能一次：先鎖定再評估；分割模型要求測試集遮罩全部經人工確認 |
| 一鍵流程、AI 分析 | 分割 → 特徵 → 分類，結果存成 CSV；AI 分析頁可看單張影像的遮罩疊圖與數值 |
| 前端 | 訓練、訓練詳細（即時曲線）、實驗、實驗詳細、模型庫、模型詳細、特徵、流程、AI 分析、遮罩草稿、草稿確認，全部接上真實資料；移除 M2 的示範提示 |

## 5. 已知限制與注意事項

1. **還沒有訓練任何正式模型**。模型好壞取決於標註數量與品質。約 176 位病人屬於小資料，信賴區間會很寬。
2. **MedSAM 不適合當主要草稿**（#44）。這是零樣本、以舊遮罩為框的結果。之後更好的做法是用你自己訓練的分割模型做「模型預測 → 人工修正」。
3. **肝脾規則草稿要靠人工確認**。真實影像上的接受率要等你確認後才知道；接受率低的話告訴我，我再調整規則。
4. **完整訓練需要數小時**。975 張、512 px、5 折、最多 60 epoch，實際時間依提早停止而定。訓練期間電腦不要進入睡眠。
5. **nnU-Net 在 Windows 上很慢**。建議先用 100 或 250 epochs。
6. **P 指數與 Grade 3 沒有已發表的定量切點**，只能當探索性指標。
