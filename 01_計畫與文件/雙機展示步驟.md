# 雙機展示步驟

> M3 醫師端的展示方式（決策 D38、D43）。B 電腦跑本系統（醫師端）；A 電腦只用瀏覽器傳圖，不用安裝任何東西。
> 設計見 [實作企劃](實作企劃.md) §5；API 見 [API規格](API規格.md) §10。

## 展示前一天（在 B 電腦）

1. 用 `start.bat` 啟動系統。M3 第一次啟動會自動更新資料庫（`c0003`、`r0005`）。
2. 到 **設定 › 醫師端** 選分析方案：
   - eGFR：`egfr/img-clin-2c@1.0.0`（候選，結果會標示「尚未臨床核准・僅供研究展示」）；
   - 分割：有分割模型再選；沒有的話腎長、回音比不會出現；
   - 按「儲存」，再按「預先載入模型」。
3. 到 **設定 › 醫師與操作者名單** 加入判讀醫師（簽核時要從名單選）。
4. 到 **臨床 › 影像接收 › 雙機展示**，按「匯出示範影像包」：
   - 產生在 `03_資料/08_匯出/示範影像包_{時間}/`；
   - 內容是主要切分**測試集**病人的去識別化影像（每側 1 張）和 `示範清單.json`；不含 eGFR、姓名、病歷號。
   - **使用前請先確認醫院同意用去識別化影像展示。**
5. 把整個「示範影像包」資料夾複製到 A 電腦（隨身碟即可）。
6. 到 **臨床 › 首頁** 看「開始前檢查」是否全部打勾。

## 展示當天

### 網路

- 兩台電腦連**同一個** Wi-Fi 或手機熱點。
- 第一次開始接收時，Windows 可能跳出防火牆詢問：請允許「私人網路」。
- 手機熱點常被 Windows 當成「公用網路」：到「設定 › 網路和網際網路」把它改成私人網路，或在防火牆允許 TCP 8443（或你在設定改的連接埠）連入。

### B 電腦（醫師端）

1. **臨床 › 影像接收 › 雙機展示**：選網路介面（只有一個時會自動選），按「開始接收」。
2. 畫面會顯示：
   - A 電腦要打開的網址，例如 `https://192.168.1.23:8443`；
   - 6 位數配對碼（10 分鐘有效，可以按「換一個配對碼」）；
   - 憑證指紋。
3. 接收中時，所有頁面頂端會顯示「雙機接收進行中」與停止按鈕。

### A 電腦（傳送端）

1. 用瀏覽器（Edge 或 Chrome）打開 B 畫面上的網址。
2. 出現「連線不是私人連線」：這是 B 電腦的自簽憑證。比對 B 畫面上的指紋後，按「進階 › 繼續前往」。
3. 輸入配對碼。輸錯 5 次會被鎖住，要在 B 按「換一個配對碼」。
4. 匯入示範影像包裡的 `示範清單.json`，再把資料夾裡的 PNG 全部拖進頁面。
   - 每個病例代碼（DEMO-01、DEMO-02…）會建立一筆檢查。
   - 不用示範清單時，可以手動填病例代碼、年齡、性別、糖尿病，再拖入影像。
5. 按「傳送」。每張會算 SHA-256，B 收到後比對；失敗的可以按「重送失敗的影像」，全部成功才會開始分析。

### 回到 B 電腦展示

1. **工作清單**：新的檢查會依序顯示「接收中 → 分析中 → AI 完成」（或「待補資料」：缺臨床資料時，影像＋臨床的 eGFR 模型會略過）。
2. **檢查工作區**：
   - 檢視器：放大、平移、亮度對比、遮罩疊圖；快捷鍵 ←／→、R／L、0–3、Enter；
   - 右欄：分析步驟、臨床資料、eGFR（整次檢查的 P(<60)）、左右腎；
   - 可以示範：排除一張影像（要填原因）、修改腎長、補填臨床資料後重新分析；「修改紀錄」抽屜會記下來。
3. **建立報告**：AI 預填腎長與 eGFR，其他欄位醫師填寫；勾「我已確認 AI 預填」→ 送簽核 → 勾選檢查清單、選判讀醫師、輸入姓名 → 簽核。
4. 簽核後產生 PDF（`05_醫師端/03_報告/{病例代碼}_{檢查}/報告.pdf`），可以開啟或列印。修訂再簽核會覆蓋同一個檔案；作廢會覆蓋成作廢版。
5. 傳送紀錄可以下載「傳送摘要」（每張的狀態、SHA-256、耗時，不含個資）。

### 結束

- 按「停止接收」（或直接關閉系統）。配對碼與私鑰隨之失效。
- 展示用的檢查可以在工作清單移入回收桶；已簽核的要先作廢。

## 常見問題

| 狀況 | 原因與處理 |
|---|---|
| A 打不開網址 | 兩台不在同一網路；或防火牆擋住（見上面「網路」）；或 B 換了網路，IP 改變了——重新開始接收 |
| 「配對碼不正確」 | 看清楚 B 畫面上的數字；過期（10 分鐘）或錯 5 次就換一個配對碼 |
| 檢查狀態「版面不符」 | 影像尺寸沒有對應的版面範本；在檢查工作區按「從最接近的範本建立」，之後可到「版面範本」微調 |
| 檢查狀態「待補資料」 | 缺年齡、性別或糖尿病（「不明」不能當成「無」）；在工作區補填後按「重新分析」 |
| 沒有腎長 | 分析方案沒有分割模型，或影像缺像素間距 |
| PDF 打不開，說被修改過 | `報告.pdf` 被外部改過或移動；在報告頁按「產生 PDF」重新產生 |
